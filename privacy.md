# Privacy Policy for Agente Mail

Last updated: 7 November 2026

Agente Mail is a personal tool, developed and used only by its author, with the author's own Google accounts. It is not distributed to or used by any other person.

## Data the app accesses

With the author's consent, the app uses the Gmail read-only permission (`https://www.googleapis.com/auth/gmail.readonly`) to read the sender, subject, date, labels and body text of messages in the author's own inbox. It does not access attachments, contacts or any other Google data, and it cannot send, delete or modify messages.

## How the data is used

The data is used only to classify messages, summarize them, translate them on request, and compose a daily digest for the author.

## Where the data is stored

Message data, classifications and access tokens are stored locally on the author's own computer. The developer operates no server and no database that receive this data. The author can delete the local data at any time.

## Who the data is shared with

- Message content is sent to Google's Gemini API to obtain the classification, summary and translation, under Google's Gemini API terms.
- A daily digest (subject lines with email addresses masked, short summaries and classifications, without full message text) is sent to the author's own private Telegram chat.

The data is not sold, not used for advertising, and not shared with anyone else. No person other than the author reads it.

## Limited Use

The use and transfer to any other app of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

## Access removal

Access can be revoked at any time at https://myaccount.google.com/permissions.
