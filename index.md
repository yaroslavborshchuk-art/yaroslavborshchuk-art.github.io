# Agente Mail

Agente Mail is a personal, single-user tool that helps its author keep track of their own email.

## What it does

Once a day, the tool reads the author's Gmail inbox in read-only mode, classifies each new message by priority and topic (for example: action required, low priority, security notice, promotion), writes a one-sentence summary of each message, and sends a short digest to the author's private Telegram chat. The author can also ask the tool to translate a message or to discuss it in a local terminal session.

## Google API access

The tool requests one Gmail permission only: read-only access to the author's own mailbox (`gmail.readonly`). It cannot send, delete, move or modify any message.

## Who can use it

The tool is not distributed and is not offered to the public. It runs on the author's own computer and is used only with the author's own Google accounts.
